# Safari ya Mkoani

Mchezo wa 3D wa mabasi ya mkoani (Dar es Salaam – Dodoma). Hauhitaji build: ni faili tuli.

## Faili
- `index.html` mchezo (Three.js kutoka CDN)
- `supabase.js` + `config.js` leaderboard (Supabase)
- `supabase/schema.sql` jedwali la `scores` na RLS

## Kuweka mtandaoni
1. Supabase: schema.sql iwe imeshaendeshwa (SQL Editor).
2. Vercel: Add New Project, chagua repo, Framework Preset = Other, bila build command, Deploy.
